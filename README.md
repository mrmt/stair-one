# Stair One

押している間だけ鳴る、16種類のノイズを出すシングルファイルの楽器。
依存パッケージもビルド工程もなく、`index.html` を Chrome で開けばそれだけで動く。

リズム、テンポ、編曲、演奏スタートの概念はない。パッドを押すと鳴り、離すと止まる。

## 使い方

`index.html` を Chrome (または Safari) で開き、4x4 のパッドを押す。

- マウス / タッチ: 押している間鳴る。マルチタッチで同時押しできる
- キーボード: `1234` / `QWER` / `ASDF` / `ZXCV` がそれぞれの行に対応
- ウィンドウのフォーカスが外れると全パッドを離す (鳴りっぱなし防止)

### MIDI コントローラ (Chrome)

1. ヘッダー右の `MIDI learn` を押す (初回は Chrome が MIDI の使用許可を求める)
2. 割り当てたいパッド、またはスライダの行を押す (点滅する)
3. コントローラのパッド / 鍵盤 (note) かつまみ / フェーダー (CC) を動かす → 割り当て完了。バッジ (`N36`, `CC21` 等) が付く
4. 2〜3 を繰り返し、`MIDI learn` をもう一度押す (または `Esc`) と演奏に戻る

- パッドには note と CC (ボタン型: 64 以上で押下) を、スライダには CC を割り当てられる
- learn 中に選択して `Delete` で割当解除、`clear all` で全解除
- 割り当てはブラウザに保存され、次に開いたときも有効
- MIDI だけでは音声を開始できないので、開いたら一度ページのどこかをクリックする
- Safari は Web MIDI 非対応のためボタンが無効になる

ネットワークには一切接続しない。

## 音の性格

16パッドそれぞれに個性 (パッチ) があるが、**全パラメータは発音ごとにランダムに決まり、発音中も少しずつ揺れ続ける**。
同じパッドを押しても毎回違う音になる。

| # | 名前 | 中身 |
| --- | --- | --- |
| 1 | Sub Saw 32′ | 32′/16′ ノコギリ波の複数本デチューン、閉じ気味のローパス |
| 2 | S&H Square 16′ | 16′ 矩形波の音程に sample & hold LFO |
| 3 | Noise Rise | ホワイトノイズ → 高Qバンドパスが開いていく |
| 4 | Moiré 7 | 8′ ノコギリ波7本のうなり・モアレ |
| 5 | Buzz 80Hz | 60〜100Hz の矩形 / ノコギリ LFO で音程を叩くブザー |
| 6 | Random Arp | ランダム音階・ランダム速度のアルペジエータ |
| 7 | Falling Res | 下降し続ける音程 + 自己発振寸前のレゾナンス |
| 8 | Siren | 上昇し続ける音程 + サイン LFO |
| 9 | Comb Metal | カープラス・ストロングの金属弦 (非整数倍の2本) |
| 10 | Bowed Comb | ノイズで擦り続けるくし形共鳴 |
| 11 | Tape Cloud | グラニュラーの粒雲 + テープの wow / flutter |
| 12 | Reverse Flutter | 逆再生の粒 + 深いフラッター |
| 13 | S&H Filter Noise | ノイズのフィルタを S&H で飛ばす |
| 14 | Growl 32′ | 32′ 矩形波に 25〜55Hz のノコギリ LFO |
| 15 | Arp Comb | アルペジオするくし形共鳴 |
| 16 | Chaos | 全部入り。LFO 形状・速度・フィルタ種別まで毎回くじ引き |

## 操作 (全パッド共通)

| スライダ | 内容 |
| --- | --- |
| attack | 立ち上がり (2ms〜4s) |
| decay | サステインへ落ちるまで (20ms〜6s) |
| release | 離してから消えるまで (10ms〜8s) |
| distortion | tanh 歪み |
| bitcrush | ビット深度とサンプルレートを落とす |
| phaser | allpass 6段フェーザーの深さ・速さ・フィードバック |
| delay time / feedback / mix | L/R で時間の違うステレオディレイ |
| volume | 出力音量 |
